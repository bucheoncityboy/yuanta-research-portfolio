글로벌 시장 브리핑 자동화와 K-Skill 오픈소스 기여

금융시장 데이터의 기준일과 출처를 검증하고, 반복적인 브리핑 작성 과정을 자동화했습니다.

GAMMA 글로벌마켓학회에서 일간·주간 브리핑을 작성하며, 지표마다 발표 시점과 거래일이 달라 자료를 반복 확인하는 문제를 발견했습니다. Python으로 ECOS·U.S. Treasury·Cboe·ECB 조회를 연결하고, FRED는 발표 지연을 확인하는 보조 경로로 사용했습니다.

미국과 한국의 최근 완료 거래일을 각각 판별하고 관측일·단위·출처를 기록했습니다. 원천 오류가 발생하면 해당 항목만 제외해 수집을 이어가며, 누락값이나 세션이 맞지 않는 수치를 임의로 채우지 않도록 구성했습니다.

학회원에게 공유한 뒤 브리핑 작성시간이 약 40분에서 10분 이내로 줄었다는 피드백을 받았습니다. 개발한 스킬은 K-Skill에 병합돼 정식 기능으로 반영됐습니다.

기업분석 자료 수집·검증 및 리포트 작성 AI 에이전트

공시와 실적, 시장자료를 교차확인하고 기업분석 보고서로 정리하는 리서치 파이프라인을 구축했습니다.

공시·재무제표·실적발표와 시장자료를 모으고, 컨센서스와 주요 이슈를 대조해 산업·경쟁 구도와 Bull/Bear 쟁점을 정리했습니다. 기업 식별부터 자료 수집, 분석, HTML 생성과 검토까지 연결했으며, 공개 README 기준 19개 종목을 지원하도록 구성했습니다.

최신 v3는 에이전트가 자료를 직접 수집하고 템플릿에 반영하는 방식입니다. 이전 v2의 Python 파이프라인과 검증 게이트를 에이전트 검토 단계로 전환했습니다. 별도 Company Analysis 스킬은 한국·미국 상장기업의 공개 공시를 대조하고, 출처·수집일·기간·단위가 확인되지 않는 정보는 누락 처리하도록 설계했습니다.

03GLOBAL MACRO / IB RESEARCHMARKET ANALYSIS

글로벌 IB 리서치 분석과 정책 파급경로 연구

해외 IB 리서치의 주요 논점을 분석하고 경제지표와 자산가격을 대조해 시장 변화의 배경을 설명했습니다.

GAMMA 글로벌마켓학회에서 해외 IB의 Rates·FX·Credit 리서치를 읽고 핵심 주장과 근거를 정리해 발표했습니다. 중립금리와 Fed 정책경로, 경제지표 연례개정에 따른 성장·물가 판단 변화를 살피며 정책 기대가 금리와 환율에 반영되는 과정을 설명했습니다.

미국의 주거·비주거 투자와 첨단기술 제조업을 비교해 경제 부문별 금리 민감도를 검토했습니다. 시장의 사전 기대와 실제 가격 반응을 구분하고, 미국 국채금리·환율·주식의 변화가 한국시장에 전달되는 경로를 일간·주간 브리핑으로 정리했습니다.

04RATES / EVENT STUDYDATA ANALYSIS

한국은행 통화정책 결정과 국고채 수익률곡선 분석

금통위 결정 전후 국고채 만기별 반응을 비교하고 정책 방향만으로 수익률곡선의 움직임을 설명하기 어렵다는 점을 확인했습니다.

국고채 3년·10년물의 공통 관측일 1,084개와 정책결정 36회를 연결했습니다. 발표 전일(D-1)을 기준으로 다음 관측일을 D+1, 다섯째 관측일을 D+5로 통일하고 만기별 금리 변화와 3s10s 스프레드를 계산했습니다.

D+1 스프레드는 19회 확대되고 17회 축소됐습니다. 정책결정 방향이 같아도 커브 반응은 달라, 선반영 가능성과 미국 금리·국내 수급을 함께 확인해야 할 변수로 정리했습니다.
